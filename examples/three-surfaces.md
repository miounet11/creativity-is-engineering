# 对照：三张皮一层肉

对应：`INTEG-1` `INTEG-2` `INTEG-3` `INTEG-4` `INTEG-5`

**表面症状：** 控制面同时有窗口、本机 HTTP、单测。有人再写一份「长跑专用脚本」，或在启动时才把身份、网络、行为拼起来。

**对条：**

- `INTEG-1`：写操作只进 service；HTTP 与 IPC 只取参
- `INTEG-2`：测试直调与线上入口走同一 normalize
- `INTEG-3`：长跑壳与桌面 import 同一份配置纯函数，不是脚本 fork
- `INTEG-4`：身份 / 网络 / 行为在写入前打成原子 bundle，不在启动后再补互相打架的字段
- `INTEG-5`：三入口职责表存在，无两处同改一份状态文件

**职责表（最低限度）：**

| 入口 | 准做 | 不准做 |
|------|------|--------|
| HTTP | 取参、鉴权、调用 service | 直接改状态文件 |
| IPC | 取参、转给 service | 在 renderer 里手写磁盘 |
| 测试 | 直调 service / normalize | 复制一份「测试专用」写入路径 |
| 长跑壳 | import 同一配置纯函数 | fork 脚本再改两周 |

**不要写进本文件的：** 真实主机、密钥、用户路径。
