# 对照：观感在打字，杠杆不在打字

对应：`MOAT-1` `MOAT-4` `MEASURE-1` `MEASURE-2`

**表面症状：** 资料页姓名和密码逐字出现，人机验证尚未勾上。操作者判断卡点是输入。

**证据（成功样本分段，墙钟相减）：**

| 阶段 | 大约墙钟 |
|------|----------|
| 启动 | 5s |
| 打开页 | 7s |
| 邮箱阶段 | 5s |
| 一次性代码 | 29s |
| 资料页（输入与验证并行） | 42s |
| 提交后取会话 | 18s |
| 全链路 | 106s |

吞吐约 3.6/min，成功率约 93%。资料页打字约 8–12s，与验证并行，墙钟 ≈ max。把打字改成瞬间填完，全链路大约 106→97s，吞吐大约 3.6→3.9/min。

**对条：**

- `MEASURE-2` 成立：并行用 max
- `MOAT-4` 成立：观感痛点 ≠ 吞吐杠杆
- 操作者随后判定「不调整，这是优势」→ `MOAT-1`
