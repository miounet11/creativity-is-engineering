# 对照：域名配置拉取失败

对应：`PACK-2`

**表面症状：** 面板从 URL 加载报 `fetch failed`。密钥栏空。

**错误诊断：** 配置坏了，或 IPC 坏了。

**证据：**

- 源站用域名拉同一文件：成功
- 目标网用同一域名：失败
- 站点已为「域名解析或 SNI 失败」留了镜像：成功

**对条：**

- `PACK-2` 要求镜像写进 manifest，不能只活在排障聊天里
- 先给操作者镜像地址，再改下一版自动回退候选列表
- 安装包无密钥、配置三条路、带密钥 URL 当密码：看 ship-standard `LAUNCH-5`（本仓已废止的 `PACK-1` / `PACK-5` 指向那里）

**不要写进本文件的：** 具体主机地址、密钥正文。
