# 纬度：不删优势

配套：[measure](./measure.md) · 例子 [timing-is-not-the-moat.md](../examples/timing-is-not-the-moat.md)

---

## 一句话

**操作者点名的优势必须写成现在时不变量；默认不准优化掉。**

## 何时用

- 有人说「慢」「笨」「可以更快」
- 行为真实度、身份一致性、反检测节奏被当成性能债
- 操作者说「这应该也是我们的优势」

上线能不能发，看 ship-standard 的 `LAUNCH-*`。本纬度只锁「创造成果有没有被自己删掉」。

## 验收句

1. 优势有一句 MUST NOT，能在评审里引用 id。
2. 观感痛点和吞吐杠杆分成两行，没有合成「所以要加速」。
3. 若削弱优势，能指出 per-call 覆盖点和风险行。

## 门禁

- [ ] `MOAT-1` 操作者若称某行为是优势，已写成现在时不变量
- [ ] `MOAT-2` 该优势有禁止清单：不准把它当 bug 修掉
- [ ] `MOAT-3` 若必须削弱优势，只允许 per-call 覆盖，并记风险行
- [ ] `MOAT-4` 观感痛点与吞吐杠杆已分开写，未混成一句「慢」
- [ ] `MOAT-5` 下一会话的规则或提示里能读到这条优势

## 禁止

- 把打字延迟调到 0 当提效
- 把 humanize 关掉当修 bug
- 用「反正能过」代替一个业务周期
- 没有分段计时就改护城河参数

## 产出

不变量句子、禁止清单、（可选）风险行。
