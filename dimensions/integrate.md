# 纬度：三张皮一层肉

配套：[pack](./pack.md)

---

## 一句话

**HTTP、IPC、测试直调收敛到同一 service；长跑壳不是脚本 fork。**

## 何时用

- 控制面同时出现窗口、本机 API、单测
- 准备再写一份「农场专用脚本」
- 身份、网络、行为在启动时才拼起来

## 验收句

1. 改状态文件的路径只有 service。
2. 面板与无窗口循环 import 同一份配置纯函数。
3. 职责表能指出三入口各自不准做什么。

## 门禁

- [ ] `INTEG-1` 写操作只进 service；HTTP 与 IPC 只取参
- [ ] `INTEG-2` 测试直调与线上入口走同一 normalize
- [ ] `INTEG-3` 长跑壳与桌面共用配置纯函数，不是脚本 fork
- [ ] `INTEG-4` 身份 / 网络 / 行为在写入前打成原子 bundle
- [ ] `INTEG-5` 三入口职责表存在，无两处同改一份状态文件

## 禁止

- 为了方便在 renderer 或路由里手改状态文件
- 复制脚本再改两周
- 启动时再补互相打架的地理与号码

## 产出

职责表、共享模块路径、（可选）架构探针。
