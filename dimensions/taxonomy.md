# 纬度：一种失败一种动作

配套：[loop](./loop.md) · 例子 [classifier-probe.mjs](../examples/classifier-probe.mjs)

长跑上线的同类门禁在 ship-standard `RESIL-*`。本纬度锁的是**创造过程**：AI 的第一产出必须是分类表，不是更快的输入。

---

## 一句话

**分类器吃真实原文；每个 kind 只映射一个 action；业务与基础设施分开。**

## 何时用

- 新开一条会失败的长跑或集成
- 模型把所有 catch 写成 retry
- 要把「失败」从操作者口语变成系统词

## 验收句

1. 测试里至少有一条对方页面或接口的原文。
2. 新增 kind 的同一 PR 里有且仅有一个 action。
3. 同一句超时时，购买前与持有资源后的动作不同。

## 门禁

- [ ] `TAX-1` 分类器吃真实原文，不只测自编枚举
- [ ] `TAX-2` 每个 kind 只映射一个 action
- [ ] `TAX-3` 第一笔是失败的分类测试，随后才是实现
- [ ] `TAX-4` 业务错误与基础设施错误两套分类，stage 是输入
- [ ] `TAX-5` 日志能区分退役 / 冷却 / 等待 / 换通道 / 降载 / 延后

## 禁止

- 用重提治疗频控
- 用整类停买治疗单个坏资源
- 用「最近全失败」当停机
- 把基础设施超时写成业务退役

## 产出

纯函数分类器、红灯测试、动作对照表。
