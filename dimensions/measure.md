# 纬度：先分段再动

配套：[moat](./moat.md) · 例子 [timing-is-not-the-moat.md](../examples/timing-is-not-the-moat.md)

---

## 一句话

**没有分段墙钟，不准把「慢」写进优化清单。并行阶段用 max，不用 sum。**

## 何时用

- 任何「卡点在输入 / 网络 / 验证」的争论
- 日志已有累计时间戳，需要相减
- 准备改 timing 参数之前

## 验收句

1. 每段有平均或中位墙钟，或明确「仅观感、本轮不改代码」。
2. 并行步骤的解释里出现 max，不出现把两段相加当墙钟。
3. 缺段的日志被标成门禁缺口，而不是用印象补齐。

## 门禁

- [ ] `MEASURE-1` 优化「慢」之前已有分段墙钟，或明确只记录观感不动代码
- [ ] `MEASURE-2` 并行阶段用 max 解释墙钟，不用 sum
- [ ] `MEASURE-3` 日志能相减出各段；缺段视为门禁缺口
- [ ] `MEASURE-4` 样本数与成功率 / 吞吐写在例子里，不写密钥
- [ ] `MEASURE-5` 没有数字的「感觉慢」未进入优化清单

## 禁止

- 用肉眼帧率代替分段
- 把并行等待和串行输入加在一起吓人
- 在例子里贴密钥、账号、内网地址

## 产出

分段表、样本数、是否进入优化清单的结论。
